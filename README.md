# The Jimmy Possum Chair — A Field Guide

A tutorial site for building a Jimmy Possum chair (a folk stick chair from
Tasmania), by Lewis Laskin.

Plain static site — HTML, CSS, and a little vanilla JavaScript. No build step.
Open `index.html` directly, or serve the folder:

    python3 -m http.server 8000

Then visit <http://localhost:8000>.

## Editing

All the text lives in `index.html`, organized into labeled `<section>`s.
Edit the words between the tags, save, and refresh.

## Deploy

Published with GitHub Pages from the `main` branch (root). Pushing to `main`
updates the live site.
