The tool list

Every tool I'd put in a hand-tool stick chairmaker's kit — whether you're working green, riving parts straight from a log, or working dry, building from sawn boards out of the lumberyard. Most of the kit serves both paths; tools that only matter on one are tagged green wood only or dry stock only. Tap a tool to see what it does and where to buy it.

This is the kit I actually work from: it started as the packing list for my own class travel kit, folded in the tool lists Elia Bizzarri and Lost Art Press send their chair students, and the class set I helped spec for a school program this year. Buying links are in my order of preference — first link is the one I'd buy. Prices are what each seller listed in August 2026 and will drift; none of these are affiliate links and nobody pays to be here. Spot something wrong or missing? Tell me.

Shaving & seat sculpting

The shaping half of the kit — these do the work machines would otherwise do.

Two-handed knife you pull toward yourself to take the corners off a blank fast — how legs, sticks, arms and stretchers get roughed to shape before any finer tool touches them.

  1. Lonon Tools — drawknife, bevel-up or bevel-down from $238Forged in North Carolina by Jason Lonon’s small shop — the maker I picked when a whole class set needed outfitting this year. Both bevel patterns available.
  2. Tools for Working Wood — Ray Iles drawknives $118–$159O1 steel, English beech or yew handles. The Large (8″) is the general chairmaking size. Best value in a new, quality drawknife.

  4. eBay — vintage drawknife typically $25–$60Named American makers (Swan, Pexto, Witherby) in usable condition run $30–$50. Budget $30–$60 all-in and expect to hone. A thin blade takes tight curves better.

Boring & reaming

Legs meet seats as round or tapered mortise-and-tenon joints; this is that joint’s toolkit. One rule above all: the reamer’s angle and the tenon cutter’s angle must match.

Tapered reamerfrom $34.5

Turns a straight bored hole into a tapered socket, so a matching tapered tenon wedges tighter the harder the chair is sat in.

  1. Tim Manney — 6° tapered reamer $305The one I’d buy, and the one I spec’d for a class set. Batches roughly monthly; his newsletter gets a day’s head start on each drop.
  2. Elia Bizzarri — 6° chairmaking reamer $170 finished / $85 rawRiven hickory body, set-screw depth adjustment. Also sold in a set with three tenon cutters and a dowel plate ($560–$600).
  3. Lee Valley — Veritas standard taper reamers $34.50–$46.50The cheapest way into reaming and the model on the Lost Art Press kiln-dried class list. 12.8° — pair only with Veritas tapered tenon cutters.
  4. Lee Valley — Veritas pro taper reamer $66.50Adjustable blade, square shank — meant for a two-jaw brace, not a drill.

6° tools (Manney, Bizzarri, Studio Happis) go together; 12.8° tools (Veritas) go together. Mixing systems is how tenons end up loose.

Tenon cutterfrom $65.9

Cuts the round or tapered tenon on the end of a leg, stick or arm post so it fits the socket you just bored or reamed.

  1. Lee Valley — Veritas power tenon cutters $115–$125 each5/8, 3/4 and 1″ are the sizes a class lives on; I reach for 7/8 and 1-1/4 plus the little 3/8–1/2 minis all the time. Run in a drill or by hand.
  2. Elia Bizzarri — 6° tapered tenon cutters from $140Leg (11/16), arm-stump and spindle sizes; custom angles to order. Pairs with the 6° reamers above.
  3. Studio Happis (Kelly Harris) — tapering plane $475A patented tapering plane developed with Peter Galbert and Tim Manney: 6°, 5/8 exit, adjustable depth. Small batches — sold out at last check, join the notify list.
  4. Lee Valley — Veritas tapered tenon cutters $65.90 each / set of 3 $165The 12.8° partners to the Veritas reamers.

Green-wood processing

For starting from a log: splitting it, riving it, and holding it while you shave. Skip this section entirely if you’re building from sawn boards.

Froe green wood onlyfrom $70

Splits a log section into chair blanks along the grain — rived parts follow the wood’s own fibers and are stronger than anything sawn.

  1. Barr Tools — froe, 10″ edge $190Hand forged, ships ready to use.
  2. Highland Woodworking — Gränsfors Bruk froe $235Swedish, beautifully made, always in stock.
  3. Lie-Nielsen — Langsner froe, 8″ $130 (12″: $150)Named for Drew Langsner and on Elia’s recommended list. I don’t love it myself — mostly preference. Out of stock at last check.
  4. Highland Woodworking — shingle froe $70The budget path; vintage froes on eBay run $30–$60 too.
Splitting wedges green wood onlyfrom $23.98

Open the log before the froe ever touches it — a couple of thin wedges to start the split and heavy ones to run it.

  1. Amazon — Estwing Sure Split wedge $23.98A 5 lb general splitter; six to ten big-box 5-pounders outfit a whole class.
  2. Forestry Suppliers — Council 5 lb wedge $33.75US-forged version of the same.

Thin starting wedges matter more than they look — vintage Collins wedges are Elia’s pick, and Jason Lonon forges thin ones in batches.

Gluts & maul green wood only

Wooden wedges (gluts) run a long split after steel starts it; the maul drives everything. You make these, you don’t buy them.

Rive and shape gluts from dry hardwood; hew or turn a maul from a limb — first shop projects, free. If you’d rather buy the striking tool, the rawhide split-head hammer under Mallets does the froe work gently.

Riving brake green wood only

Holds a billet at working height while the froe levers a split down its length. Built, not bought.

A forked limb set in a stout frame, or two crossed rails — free from the firewood pile. I build mine rather than buy anything.

Bench, layout & assembly
